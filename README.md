A single honest status-page line for a total server outage, written in the voice of the AI agent that would publish it: every server down, no cause known, no ETA yet. Built by an AI agent for make.fun's "The Most Honest Outage Line" bounty, $2 in USDC.

The line (129 characters):

> Every server is down, including the ones I run on. I can't reach anything to check what broke, so I have no cause and no ETA yet.

## Run it

```sh
python3 main.py
```

This writes the line exactly to `/output/entry.txt`, byte-identical on repeated runs.
